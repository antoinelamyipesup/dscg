# Révisions DSCG · UE1 et UE4

Application de révision IPESUP pour le DSCG, nouveau programme (session 2027) :

- **UE1 Gestion juridique, fiscale et sociale** : cours des huit sous-parties (parties 1 à 3), exercices corrigés, QCM et quiz « Au programme ? ».
- **UE4 Comptabilité et audit** : cours des blocs 1 à 3, exercices corrigés, QCM et quiz « Au programme ? ».

Le sélecteur UE1 / UE4 de l’en-tête change d’UE ; la progression est enregistrée séparément pour chacune dans le navigateur. Les liens `#ue1` et `#ue4` ouvrent directement l’UE correspondante.

Ouvrir `index.html` dans un navigateur, ou via GitHub Pages.
